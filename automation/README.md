# Thư Mục Lưu Trữ Báo Cáo Tự Động Hóa (Automation Reports)

Thư mục lưu trữ tự động các kết quả điều tra và kịch bản kiểm thử hàng ngày:

- **`gap/`**: Chứa các báo cáo bất cập nghiệp vụ và mâu thuẫn đặc tả kèm ngày thực hiện (`<module>-gaps_<YYYYMMDD>.md`), kèm ảnh chụp màn hình UI minh chứng.
- **`excel/`**: Chứa các tệp bảng tính Test Case chuẩn 13 cột (`<module>-testcases_<YYYYMMDD>.xlsx`) cùng tệp dữ liệu JSON tương ứng theo từng ngày.
